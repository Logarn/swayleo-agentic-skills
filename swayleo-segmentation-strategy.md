# swayleo-segmentation-strategy

Ask which client to prioritize if unavailable in the brief. Inspect actual segment definitions, data fields, consent state, exclusions, refresh behavior and audience overlap. Never infer criteria from segment names alone. Map lifecycle stages and relevant behavior to proposed segments; state exact inclusion, exclusion, window and event requirements. Explain the audience and campaign use in plain language. Treat proposed thresholds as hypotheses needing validation, not universal rules. Distinguish consent from engagement. Return current-state gaps, proposed definitions, priority and review cadence. Do not change audiences or send campaigns without authorization.
