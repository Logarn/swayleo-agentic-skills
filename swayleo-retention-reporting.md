# Retention Reporting

## Purpose and provenance

New workflow filling the reporting gap; use installed analytics skills for deeper analysis.

This workflow applies across brands by substituting the current brand's sources, account, scope and approval rules. It is a reusable instruction set, not evidence that a live system is configured.

## Inputs

ESP and commerce exports/access, reporting dates/timezone, attribution settings, campaign/flow IDs, revenue definition, consent/delivery metrics and comparison period.

If an input is unavailable, identify its effect and continue work that does not depend on it. Do not fill factual gaps with another brand's assumptions.

## Workflow

1. Define the question and each metric before calculating. Record grain, currency, timezone, attribution window/model, refunds and order versus recipient counting.
2. Check freshness, duplicate rows, missing IDs and join cardinality. Reconcile aggregate totals with the source before explaining performance.
3. Separate campaigns, flows and channels; attribution may overlap. Do not sum attributed revenue across overlapping systems as incremental revenue.
4. Compare like-for-like periods and account for audience size, send volume, promotions, deliverability and seasonality.
5. Use delivered-message denominators where appropriate and state them. Treat opens cautiously; distinguish click/order measures from platform-reported attribution.
6. For retention, define cohorts, repeat-purchase window and eligibility. A customer without enough observation time is not automatically lapsed.
7. Explain changes with measured decompositions where possible. Separate observed drivers, plausible hypotheses and causal claims needing an experiment.
8. End with a short decision/action list and evidence links. Do not imply a recommendation was implemented.

## Deliverable

Metric definitions; scorecard; period/cohort comparison; validated drivers; limitations; prioritized next actions. Keep calculations inspectable.

Use the output worksheet inside the downloadable library ZIP to structure a working draft. Adapt it to the requested deliverable; do not create extra files unless useful.

## Example

Attributed revenue increased because send volume doubled while revenue per delivered message fell. Report both rather than calling the creative more effective.

## Verification and completion

Definitions and denominators clear; sources reconcile; overlaps disclosed; cohorts eligible; uncertainty visible; actions follow the evidence.

Report what was completed, the source or saved record that proves it, and any unresolved blocker. Distinguish a draft, a saved change and a live action. Publishing, posting, scheduling or changing live systems requires the corresponding user request and available tools.
