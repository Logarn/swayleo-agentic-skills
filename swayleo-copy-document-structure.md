# Copy Document Structure

## Purpose and provenance

Recovered from strategy writing and master-template work; client-specific overrides remain scoped.

This workflow applies across brands by substituting the current brand's sources, account, scope and approval rules. It is a reusable instruction set, not evidence that a live system is configured.

## Inputs

Canonical document, exact master/template, current client instructions, existing copy, target tabs and required campaign/flow IDs.

If an input is unavailable, identify its effect and continue work that does not depend on it. Do not fill factual gaps with another brand's assumptions.

## Workflow

1. Read the approved reference before reproducing row labels. The historical default is Field | Copy | Inspo with 7-row inbox and 22-row email tables; retrieve the actual labels rather than inventing them from the counts.
2. Check for a later explicit client-specific override such as removing Inspo or using a particular font. Apply it only within that instruction's scope, not automatically to all brands.
3. Preserve native tables, dropdowns, chips, comments, hyperlinks and tab structure. Do not turn controls into plain text for convenience.
4. Add the detailed campaign/email strategy immediately before its writing section. Maintain a stable mapping between calendar, strategy and copy IDs.
5. Prefill the first-column labels from the approved master. Leave writing cells blank unless actual copy exists or drafting is requested. Preserve existing supplied copy exactly during a structure-only pass.
6. Guard native writes against concurrent revisions. Apply named styles before local font overrides; preserve effective inherited bold and heading hierarchy.
7. Verify all rows, labels, blank cells and mapped sections natively, then render relevant pages for split tables, orphan headings, blank pages and logo-only pages.
8. Do not declare a master ready to clone while known formatting or structure work remains.

## Deliverable

Updated target sections; table-count/label checks; preserved-copy check; rendered layout findings; unresolved template decisions.

Use the output worksheet inside the downloadable library ZIP to structure a working draft. Adapt it to the requested deliverable; do not create extra files unless useful.

## Example

A formatting pass should not turn a reviewer's commented heading into a new disconnected heading or fill blank copy cells with a generated strategy.

## Verification and completion

Correct master and overrides; actual labels verified; existing copy/comments retained; native controls remain native; layout proof supports readiness.

Report what was completed, the source or saved record that proves it, and any unresolved blocker. Distinguish a draft, a saved change and a live action. Publishing, posting, scheduling or changing live systems requires the corresponding user request and available tools.
