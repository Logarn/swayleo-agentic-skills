# swayleo-call-to-tasks

Use the transcript and after-call notes together; preserve links and timestamps. Extract actionable commitments, not every discussion point. For each task record client, action, owner, call date, due date, source and status. Explicit deadlines override the default call date +2 days. If calendar versus working days has not been agreed, flag the ambiguity rather than claiming a firm date. Flag missing owners and contradictory instructions. Compare with existing tasks before proposing new ones. Prepare tasks on the call day; if processing later, preserve the original call date. Create in Monday.com only when the user has authorized task creation and access exists; otherwise return an import-ready table. Do not claim a live automation exists.
