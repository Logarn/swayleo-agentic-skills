# swayleo-monday-slack-sync

Inspect the actual board schema and Slack tracking format before proposing a sync. Agree the authoritative system and field ownership. Map task ID, client, title, owner, status and due date; preserve a durable cross-system ID. Specify supported triggers, conflict handling, duplicate prevention, retries, loop prevention and deletion behavior. Distinguish Slack messages, Slack Lists and other task integrations because their APIs and capabilities differ. Explain unsupported fields and required connections. Start with a small authorized pilot and verify create/update/status flows. Never claim a live sync or daily automation without execution evidence.
